# Legacy Bot Privacy Policy

Effective date: June 24, 2026

This Privacy Policy explains what data Legacy Bot collects, why it is collected, and how it is used. By adding Legacy Bot to a Discord server or using its commands, you agree to this policy.

## Data Legacy Bot collects

Legacy Bot may collect and store the following data when needed to provide bot features:

### Server data

- Discord server ID
- Server name
- Server member count
- Server join and removal events for bot install tracking
- Configured report channel ID
- Configured milestone role IDs
- Configured vote reward role ID
- Premium status for the server

### Growth data

- Daily join counts
- Daily leave counts
- Daily net growth totals
- Growth alert settings
- Daily report status

### User data

- Discord user ID for Top.gg vote rewards
- Top.gg vote count
- Vote streak
- Last vote timestamp
- Temporary vote premium expiration time
- Vote reward event history

### Billing-related data

When premium checkout or billing webhooks are used, Legacy Bot may store:

- Discord server ID connected to a checkout
- Discord user ID of the purchaser or admin who generated checkout
- Lemon Squeezy subscription ID
- Lemon Squeezy customer ID
- Order ID
- Subscription status
- Renewal or expiration timestamps
- Customer portal or payment update URLs if provided by Lemon Squeezy
- Billing webhook event data used for troubleshooting

Legacy Bot does not collect Discord message content for analytics. Message content intent may be used only so prefix commands can work.

## How data is used

Legacy Bot uses collected data to:

- Provide growth analytics
- Track server joins and leaves
- Display server growth dashboards
- Configure milestone roles
- Manage Top.gg vote rewards
- Assign or remove vote reward roles
- Enable and maintain premium access
- Process Lemon Squeezy billing webhooks
- Provide support and troubleshooting
- Protect against webhook abuse

## Data sharing

Legacy Bot does not sell user data.

Data may be processed by third-party services required for bot operation, including:

- Discord, for bot functionality
- Top.gg, for vote webhook events
- Lemon Squeezy, for premium billing
- Hosting providers such as Railway, if used to run the bot

## Data retention

Legacy Bot keeps configuration, growth, vote, and billing data while it is needed to provide bot features, maintain premium access, debug billing issues, or support server owners.

Some data may remain after the bot leaves a server if it is needed for billing records, fraud prevention, support, or operational logs.

## Data deletion

Server owners may request deletion of server-related data through the official Legacy Bot support server:

https://discord.gg/7htnU8d2bm

Some billing records may need to be retained for legal, accounting, fraud prevention, or payment support reasons.

## Security

Legacy Bot uses webhook signature or authorization checks for supported webhooks. Access to bot data should be limited to the bot owner and authorized hosting systems.

No system can be guaranteed completely secure, but Legacy Bot is designed to store only the data needed for its features.

## Children's privacy

Legacy Bot is intended for Discord servers and users who are allowed to use Discord under Discord's Terms of Service. Legacy Bot does not knowingly collect personal data from children outside the normal operation of Discord bot features.

## Changes to this policy

This policy may be updated as Legacy Bot changes. Continued use of the bot after updates means you accept the revised policy.
